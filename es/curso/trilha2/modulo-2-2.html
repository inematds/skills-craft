🎨 Web y frontend

Con 4.694 skills e 4,5M instalaciones, es el grupo más maduro para quienes programan front. Las tres referencias tienen el respaldo de sus proveedores y un número altísimo de instalaciones: el riesgo de instalar es bajísimo.

frontend-design

488k

anthropics/skills

Directrices de diseño de la propia Anthropic. Fuente oficial + 488k installs = la referencia para una interfaz bonita y coherente.

vercel-react-best-practices

443k

vercel-labs/agent-skills

Buenas prácticas de React de Vercel, propietaria de Next.js. Descripción enfocada en generar y revisar componentes. Composición perfecta con la siguiente.

web-design-guidelines

358k

vercel-labs/agent-skills

Pautas de diseño web: diseño, espaciado, accesibilidad. Atómica y componible con frontend-design.

💡 Combo recomendado

frontend-design + vercel-react-best-practices + web-design-guidelines = un agente front completo, con cada pieza comprobable por separado.

🤖 AI / LLM / Agentes

El grupo más grande del catálogo: 12.693 skills e 12,9M instalaciones. Es el corazón del ecosistema: incluye las herramientas que crean otras skills.

SkillFuenteInstalaciones
agent-browservercel-labs332k
skill-creatoranthropics246k
vercel-composition-patternsvercel-labs195k

Por qué skill-creator es especial

skill-creator (246k, anthropics) es la herramienta canónica para crear skills; es meta: una skill que enseña al agente a escribir skills. Es la referencia de anatomía que estudiarás en la Trilha 3.

agent-browser (332k) le da al agente control del navegador para probar y extraer datos; vercel-composition-patterns (195k) enseña a componer componentes y agentes.

💡 Empieza por aquí

Si solo vas a instalar una skill de este grupo, instala skill-creator: te enseña a evaluar y crear todas las demás.

🗄️ Datos y bases de datos

1.385 skills e 0,79M instalaciones. Grupo de menor volumen, pero donde brilla la regla «prefiere al proveedor» del módulo 2.1: las mejores las escriben los propios bancos.

✗ Evítalo para SQL/Postgres

  • ✗"sql-helper" genérico de repo sin propietario
  • ✗Una skill que mezcla cinco bases de datos diferentes
  • ✗Sin actualizaciones desde los cambios de Postgres

✓ Las referencias

  • ✓supabase-postgres-best-practices — 203k · supabase
  • ✓supabase — 99k · supabase
  • ✓neon-postgres — 38k · neondatabase

Respaldado por el proveedor = la empresa que desarrolla la base de datos escribe las prácticas:

npx skills add supabase/...        # supabase-postgres-best-practices (203k)
npx skills add neondatabase/...    # neon-postgres (38k)

El porqué

supabase-postgres-best-practices lidera con 203k porque viene de quienes operan Postgres a escala. Confianza máxima: la fuente conoce los edge cases que nadie documenta.

☁️ DevOps y Cloud

Solo 907 skills, pero 8,3M installs — el segundo con mayor volumen de instalaciones. El caso emblemático es la suite microsoft/azure-skills: cinco skills coherentes, cada una con entre ~358k y 360k installs.

F

microsoft-foundry

~360k

Plataforma de IA de Microsoft (Azure AI Foundry). La más completa de la suite.

AI

azure-ai

~358k

Servicios de IA de Azure. Se pueden combinar con los demás de la suite.

D

azure-deploy · azure-diagnostics · azure-prepare

~358-360k

Deploy, diagnóstico y preparación del entorno: cada etapa del ciclo es una skill atómica.

💡 La lección de la suite

Microsoft no creó una "azure-everything". Creó cinco skills enfocadas (foundry, ai, deploy, diagnostics, prepare) que se complementan entre sí — exactamente el patrón de alcance del módulo 2.1, y por eso dominan el nicho con instalaciones enormes.

5

🧪 Pruebas y QA

1.339 skills e 0,60M instalaciones. Grupo reducido, pero importante: demuestra que las skills no se limitan a los stacks; también codifican disciplina de ingeniería.

test-driven-development

107k

obra/superpowers

Una skill de proceso: enseña al agente a escribir la prueba antes que el código. No habla de un framework, sino de un método. Muestra que una skill puede codificar disciplina, no solo sintaxis.

playwright-best-practices

45k

pruebas E2E

Buenas prácticas de pruebas end-to-end con Playwright. Atómica y específica: se activa solo cuando escribes pruebas de browser.

Skill de proceso vs. skill de stack:

test-driven-development   → COMO trabalhar (método, vale para qualquer linguagem)
playwright-best-practices → COM O QUE trabalhar (ferramenta específica)

💡 Perspectiva

Las skills de proceso como TDD están subestimadas. Cambian el comportamiento del agente en cualquier proyecto, no solo en un stack: un ROI altísimo por skill instalada.

6

📈 Marketing / Office / Finance

El ecosistema va mucho más allá de los desarrolladores. Hay grupos enteros para el trabajo no técnico: Marketing y SEO suma 2,3M installs, y Office&Files y Finance&Business tienen sus propias vitrinas.

marketing-psychology

84k · coreyhaines31

Disparadores psicológicos aplicados al copy y las campañas. Autor con trayectoria en marketing: fuente confiable fuera del mundo dev.

lark-slides

139k · larksuite

Generación de diapositivas en Lark. Respaldada por el proveedor (larksuite/cli): la propia suite ofimática escribe la skill.

stripe-best-practices

stripe/ai

Buenas prácticas de pagos de la propia Stripe. Para integrar cobros, la fuente oficial es insustituible.

El patrón se repite

Incluso en grupos de negocio, se aplican las mismas señales: lark-slides y stripe-best-practices cuentan con el respaldo de sus proveedores; marketing-psychology viene de un autor con reputación en el área. Descripción clara, alcance enfocado, fuente confiable: da igual si es código o copy.
