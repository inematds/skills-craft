🧭 Por qué existe un "starter pack"

Con 39.366 skills en el catálogo, nadie empieza por la cola larga. Tú empiezas por las skills que son, al mismo tiempo, muy instaladas (señal de que funcionan), bien escritas (sirven como modelo) y de fuentes confiables (vercel-labs, anthropics, supabase). Instalar y leer estas skills es el atajo más rápido para entender cómo es una buena skill por dentro.

✗ Empezar mal

  • ✗Instalar skills aleatorias de la cola larga
  • ✗Copiar una skill con 3 instalaciones como "modelo"
  • ✗Intentar crear la tuya antes de leer una buena

✓ Empezar por el pack

  • ✓Instalar 4-8 skills canónicas y leer sus SKILL.md
  • ✓Ver cómo los actores serios redactan la description y el cuerpo
  • ✓Obtener utilidad inmediata mientras aprendes el formato

💡 Instalar es leer gratis

Cada skill que instalas se convierte en un archivo SKILL.md en tu proyecto, en skills/ o .claude/skills/. Abre estos archivos: el starter pack también es la mejor colección de ejemplos comentados que encontrarás.

2

🔎 La indispensable: find-skills

Si vas a instalar solo una, instala esta. find-skills (vercel-labs/skills) es la skill más instalada del planeta — 1.802.925 instalaciones — y hace una sola cosa a la perfección: enseña al agente a buscar, evaluar e instalar por sí solo otras skills del catálogo. Es la meta-skill que desbloquea todas las demás.

find-skills

1.802.925 instalaciones

Qué hace: le da al agente la capacidad de buscar en skills.sh con lenguaje natural, comparar candidatas e instalar la mejor, sin que tengas que abrir el sitio.

Por qué se incluye en el paquete: convierte al agente en curador de su propio ecosistema. Tú pides "busca una skill para X" y lo resuelve. Es el punto de entrada a todo.

instalar:

$ npx skills add vercel-labs/skills

💡 ¿Por qué 1,8M y no 488k?

find-skills tiene el doble de installs que la segunda porque se instala como requisito previo de casi todo flujo de descubrimiento. Ventaja de «llegó temprano y se convirtió en infraestructura»: exactamente el sesgo del recuento de installs que la Trilha 1.5 va a analizar.

3

🎨 El trío de frontend

Web y frontend es el segundo grupo más grande del catálogo, y tres skills dominan: las dos referencias de diseño de vercel-labs e a anthropics/skills. Aunque no seas desarrollador frontend, leerlas muestra cómo escribir una skill de «guía de estilo»: instrucciones de estilo que el agente aplica sin que tengas que repetirlas.

frontend-design · anthropics/skills

488.299

Qué hace: genera interfaces pulidas y con buen gusto, que evitan el aspecto genérico de la IA. En el pack: es la skill de la propia Anthropic: referencia sobre cómo escribir una skill de diseño y un disparador de calidad visual inmediata.

vercel-react-best-practices · vercel-labs/agent-skills

443.261

Qué hace: codifica las buenas prácticas de React/Next que recomienda Vercel — composición, server components, patrones de datos. En el pack: mejora cualquier código React que escriba el agente y muestra cómo condensar todo un stack en un SKILL.md.

web-design-guidelines · vercel-labs/agent-skills

358.627

Qué hace: directrices de diseño, tipografía, espaciado y accesibilidad aplicadas a cualquier UI. En el pack: complemento perfecto de frontend-design: una se ocupa de «cómo construir» y la otra de «cómo debería verse».

instalar el trío:

$ npx skills add anthropics/skills
$ npx skills add vercel-labs/agent-skills   # traz react + design guidelines
4

🤖 Las dos de agentes: skill-creator y agent-browser

Dos skills del grupo AI/Agents merecen incluirse desde el principio porque cambian lo que hace tu agente puede hacerlo. Una le enseña al agente a crear nuevas skills; la otra le da un navegador.

skill-creator

246k

anthropics/skills

Haz: guía al agente para escribir, revisar y optimizar SKILL.md. En el pack: es la fuente canónica de "cómo debe ser una skill": la usarás en la Trilha 1.4 para crear la tuya.

agent-browser

332k

vercel-labs

Haz: automatiza la navegación, completa formularios, toma screenshots y extrae datos de páginas. En el pack: desbloquea casos de uso reales (probar la UI, extraer datos) con una sola instalación.

instalar:

$ npx skills add anthropics/skills      # skill-creator
$ npx skills add vercel-labs/agent-skills  # agent-browser

💡 Las skills del mismo repo vienen juntas

Varios nombres del pack están en el mismo repositorio (anthropics/skills incluye frontend-design + skill-creator; vercel-labs incluye varias). Un npx skills add owner/repo puede instalar un paquete entero de una sola vez.

5

🗄️ Datos y proceso: supabase + TDD

Para cerrar el paquete con algo más que frontend, dos skills de distintos dominios muestran la amplitud del catálogo: una de datos (la líder del grupo Data) y una de proceso de ingeniería (la referencia de la comunidad superpowers).

supabase-postgres-best-practices · supabase

203k

Qué hace: enseña al agente a escribir SQL, RLS y esquemas de Postgres según las recomendaciones de Supabase. En el pack: es la skill más instalada de Data & Databases y un excelente ejemplo de skill de proveedor (vendor) creada por el propio equipo del producto.

test-driven-development · obra/superpowers

107k

Qué hace: hace que el agente escriba la prueba antes del código, en un ciclo red-green-refactor. En el pack: mejora la calidad de CUALQUIER tarea de código y es el ejemplo canónico de skill de "proceso": no da herramientas, cambia el comportamiento.

instalar:

$ npx skills add supabase/supabase
$ npx skills add obra/superpowers

💡 Tres tipos de skill en el pack

Observa que el starter pack cubre los tres tipos que volverás a encontrar en el curso: meta (find-skills, skill-creator), guideline/vendor (frontend, react, supabase) y proceso (TDD). Conocer uno de cada tipo ya te da vocabulario para el resto.

6

📦 El kit mínimo recomendado

No necesitas instalar las ocho de una vez. Empieza por kit mínimo de 3 — lo esencial para cualquiera — y amplíalo según tu trabajo. Aquí está el orden recomendado, paso a paso.

1

Kit mínimo (para todos): find-skills + skill-creator

Con el descubrimiento y la creación ya puedes encontrar todo lo que existe y crear lo que falta. Es el par fundacional. Añade test-driven-development si escribes código.

2

Si haces frontend: + frontend-design + web-design-guidelines

La dupla de diseño de Anthropic y Vercel cubre «construir» y «verse bien». Agrega vercel-react-best-practices si el stack es React/Next.

3

Por necesidad: agent-browser y supabase

agent-browser cuando necesites automatizar la web; supabase-postgres-best-practices cuando el proyecto tenga Postgres. Instálalas según las necesites: no acumules skills que no usas.

el kit mínimo en dos comandos:

$ npx skills add vercel-labs/skills   # find-skills
$ npx skills add anthropics/skills    # skill-creator + frontend-design

💡 Menos es más

Cada skill instalada consume un poco del contexto del agente (el name + description siempre permanece cargado). Un conjunto reducido y pertinente funciona mejor que 40 skills compitiendo por la atención. Instala las que usas y elimina las que no usas.
